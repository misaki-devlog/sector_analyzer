# sector_analyzer

## 概要（Overview）
業界をプルダウン式で選択し、選択された業界ごとに重視する指標を変えて表示します。そしてそこにデータを入力することができます。
将来的には、その数字と業界の基準値との差で健全性などを判断することもできるようにしていきたいです。

  「どのような企業データを用意し、どういうステップ（並べ替え ➔ 平均値計算 ➔ 絞り込み）で分析を進めるか」という、システムの骨組みや仕様を徹底的に考案しました。
- コード実装（AIが担当）：
  自身が設計した仕様と要件をAIに指示し、実際のPython（pandas）のコード生成・最適化を任せる形で効率的に開発しました。
  
## 使い方（Usage）
1. 調べたい企業の財務データを取得する（四季報やirなど）
2. Pythonをインストールする
3. Stramlitライブラリをインストールする
4. 以下を実行する
　sector_analyzer.py
5. ターミナルに表示されたURL(ローカルでもネットワークでも可)を開く
6. 調べたい企業に当てはまる業界をプルダウン式で選択する
7. 表示された指標（ROEや営業利益率など）に＋－のボタンで数字を入力する
8. 「この内容で判定する」を押す
9. 結果を確認する

## 考えたこと（thoughts）
- 「〇〇率」という名前の指標は%表示で十の位、一の位、小数第一位でそれぞれ＋とーで変えられる仕組みの方が使いやすい
- 営業利益率などは四季報などにはそのまま書いていないから、売上総利益と営業利益を入力するところを作って計算する仕組みにしたい
- ブランド力など数字に起こせない指標は使わない
- 業界を選べと言われてもすぐにわからないこともあるだろうから、業界選択で困ったときのヘルプとして、そこ企業の行っている事業から業界を調べられる機能も付けたい
- 企業によっては複数の業界にまたがって事業を展開しているところもあるから、業界を複数選択できるようにすることも検討したい
- 今後は四季報の記者コメントを入力して総合的に健全性を財務の強気度を判断する機能を追加したい
- わからない指標に関してはスキップ機能をつけて、それを含めずに判断する仕組みにしたい
- 業界名の先頭にアイコン的なものをつけたい
- 数値は小数第二位までは必要ない
- 業界ごとの代表的な企業に関しては業界を選択した後に「代表企業を見る」みたいな項目を作って確認できるようにしたい
- 調べたい企業の数値を入力したら代表的な企業(15社から任意で選択)と比べて分析することもできるようにしたい。
- 指標ごとに意味と数値の捉え方(高いといいのか低いといいのか)などの早見表も確認することができるようにしたい
